# Find Your 4th

A padel app for filling the last spots in a game. It does not book courts.

```bash
npm install
cp .env.example .env.local
npm run dev
```

The screens run without Supabase. Signing in, posting, and joining need a project. The steps that only you can do are in [docs/MANUAL-SETUP.md](docs/MANUAL-SETUP.md).

```bash
npm test
```
